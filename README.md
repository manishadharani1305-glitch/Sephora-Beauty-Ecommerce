
### **Sephora Beauty E-Commerce Website**

**Overview:** The **Sephora Beauty E-Commerce Website** is an online shopping platform developed to provide customers with a secure, user-friendly, and convenient way to purchase beauty and cosmetic products. The system allows users to register, log in, browse products, search and filter items by category or brand, add products to the shopping cart or wishlist, place orders, make secure online payments, and track deliveries. Administrators can efficiently manage products, categories, brands, customer accounts, orders, inventory, and sales reports through an admin dashboard. The project aims to simplify online beauty shopping while ensuring fast performance, data security, and an enhanced customer experience.

**Project Objectives:** 🎯 Design a modern and responsive beauty e-commerce platform. 🎯 Provide secure customer registration and login. 🎯 Enable easy product browsing, searching, and filtering. 🎯 Support shopping cart and wishlist functionality. 🎯 Implement secure payment processing. 🎯 Manage customer orders and inventory efficiently. 🎯 Generate sales reports for administrators. 🎯 Improve the overall online shopping experience.

**Key Features:** 🎯 Customer Registration & Login 🎯 Product & Category Management 🎯 Brand Management 🎯 Product Search & Filter 🎯 Shopping Cart 🎯 Wishlist 🎯 Order Management 🎯 Secure Online Payment 🎯 Order Tracking 🎯 Inventory Management 🎯 Product Reviews & Ratings 🎯 Admin Dashboard 🎯 Sales Report Generation.

**Database Modules:** 📁 Customer 👤 Admin 🛍️ Product 📂 Category 🏷️ Brand 🛒 Shopping Cart ❤️ Wishlist 📦 Orders 📋 Order Items 💳 Payment 🚚 Delivery 📊 Inventory ⭐ Reviews 🎁 Offers & Coupons.

**Database Concepts Used:** 📌 Entity Relationship (ER) Diagram 📌 Relational Schema 📌 Primary Keys 📌 Foreign Keys 📌 Normalization (1NF, 2NF & 3NF) 📌 SQL Queries 📌 CRUD Operations 📌 Joins 📌 Aggregate Functions 📌 Constraints 📌 Data Integrity.

**Technology Used:** 💻 Frontend – HTML, CSS, JavaScript 💻 Backend – Node.js, Express.js 🗄️ Database – MongoDB/MySQL 📝 Language – SQL & JavaScript 📐 Design – ER Diagram 📄 Documentation – Microsoft Word 🔄 Version Control – Git & GitHub.
